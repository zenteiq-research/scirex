# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions or pull requests.**

Report suspected vulnerabilities privately through GitHub:
[**Report a vulnerability**](https://github.com/zenteiq-research/scirex/security/advisories/new)
(the repository's **Security** tab, then **Report a vulnerability**). Only the
maintainers can see the report.

If you cannot use GitHub, email the ZenteiQ SciML Research Team at [**research@zenteiq.ai**](mailto:research@zenteiq.ai)
with the subject line "Security: ScireX". Do not put exploit details in a
public place.

Please include, where possible:

- a description of the vulnerability and its impact,
- the affected version(s) or commit,
- a minimal reproduction or proof of concept,
- any suggested remediation.

## What to expect

- We aim to acknowledge a report within a few business days.
- We will investigate, keep you informed of progress, and coordinate a fix and
  disclosure timeline with you.
- Please give us a reasonable opportunity to remediate before any public
  disclosure.

## Supported versions

Security fixes are provided for the latest released version of ScireX.
Older versions may not receive fixes; upgrade to the latest release where
possible.
