# Governance

## Project identity and ownership

**ScireX is a ZenteiQ open-source project.** It is developed and
maintained by **ZenteiQ AiTech Innovations Pvt. Ltd.** For all ZenteiQ-owned
material, the public copyright holder, entity author and maintainer identity is
ZenteiQ AiTech Innovations Pvt. Ltd.

Public governance and attribution decisions for the project rest with ZenteiQ.
This document describes how the project is owned, maintained and attributed in
public; it does not change the open-source licences that apply to the code and
content (see [LGPL v3 licence](LICENSE), [GPL v3 licence](COPYING) and [Notice](NOTICE)).

## Public attribution policy

To present ScireX as a ZenteiQ project rather than as software authored
by named individuals, the following rules apply to public-facing material:

- Use **"ScireX: A ZenteiQ Open-Source Project"** as the public
  project identity.
- For ZenteiQ-owned files, use **"ZenteiQ AiTech Innovations Pvt. Ltd."** as the
  copyright holder and entity author.
- Do **not** add individual employee names to source-file headers, README
  author lists, package author fields, documentation footers or release notes
  merely because they implemented the code.
- Do **not** maintain a public `AUTHORS` file listing ZenteiQ employees. Where a
  project-history page is useful, describe teams and functions rather than
  individual implementation authors.
- Wherever repository tooling asks for author, maintainer or owner information,
  use the organization or team identity (**ZenteiQ AiTech Innovations Pvt. Ltd.**
  as author, **ZenteiQ SciML Research Team** as maintainer).

This is an attribution and repository-governance choice. It must **never** be
used to obscure third-party ownership, external contributor attribution
required by a licence or agreement, or patent inventorship. ZenteiQ maintains
accurate internal engineering provenance, employment/contractor IP-assignment
records and invention records separately from public attribution.

## Maintainers

The project is maintained by the **ZenteiQ SciML Research Team**. Code ownership for
review routing is defined in [`.github/CODEOWNERS`](.github/CODEOWNERS) using a
ZenteiQ team alias rather than individual employee handles.

## Contributions

Contribution terms, including the licence that applies to contributions, are
described in the [Contributing guide](CONTRIBUTING.md). External contributors must sign the
[Contributor Licence Agreement](CLA.md) before their contributions can be merged.

## Public release model

The canonical engineering repository is maintained by ZenteiQ with normal
developer attribution and internal provenance. Public releases are published as
approved, reviewed snapshots. Where an organization-only public history is
required, releases are produced by ZenteiQ-controlled automation under an
approved ZenteiQ machine / GitHub App identity rather than an individual
employee account.
